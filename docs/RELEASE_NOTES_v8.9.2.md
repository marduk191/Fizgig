# Fizgig v8.9.2: every LoRA run moves

- **Move to… works for every LoRA run:** standard, edit and slider LoRAs, with more than one subject, **Leave the rest of the model alone** or **Fizgig LoRA Isolation**. Every folder the run trains from goes with it (Subjects 2 to 4, an edit run's originals and extras, a slider's other end), and so do the files it names (an edit run's test photo, the Samples tab's reference picture, a thumbnail). Captions you edit over there come back into each folder. Only a fine-tune can't move. Tested end to end, there and back, with a two-subject Fizgig LoRA Isolation run, a slider and an edit LoRA. [Move a run](https://github.com/shootthesound/Fizgig/blob/master/docs/MOVE_RUN.md#what-can-move)

Everything new in 8.9: [Fizgig v8.9.0 release notes](https://github.com/shootthesound/Fizgig/releases/tag/v8.9.0).

**Updating:** update Fizgig on both computers (a move needs the same version on each), and restart your pods.
