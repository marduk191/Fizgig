# Fizgig v8.9.8: maintenance

- **Sample prompts are a numbered list.** On the Samples tab each prompt has its own box, every other one shaded, across the full width, growing to fit a long prompt. The numbers match the gallery's Prompt 1, 2, 3. Enter starts a new prompt, Backspace at the start of one joins it to the one above, pasting several lines makes one prompt each, and × removes one. In the gallery and Prompt × epoch, hover over a prompt to see all of it (thanks @CognitiveDiffusion, #238).
- **The Training tab is tidier.** It opens with only Output and Training Parameters open; click any other card's heading to open it, and an open card's heading is shaded. The cards every run uses come first (Base Model, Output, Training Parameters, then Edit pairs, Slider or Fine-tune for those kinds, Memory & Precision, Optimizer, Other Options), and the features you choose to use, Masked training and Subjects, sit under an **Extras** divider.
- **Extract takes any rank.** Target rank offers 1 to 128, and Other… takes any number, so the Profiler's "Rank holding 95%" can be used as it is (thanks @mart-hill, #237).
- **The Profiler's report** no longer mentions the Open in Studio button, which went in 8.9.7.

Everything new in 8.9: [Fizgig v8.9.0 release notes](https://github.com/shootthesound/Fizgig/releases/tag/v8.9.0).

**Updating:** update Fizgig on your computers, and restart your pods.
